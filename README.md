# StudyHub

StudyHub is a collaborative learning and resource sharing app built in Java Swing with Oracle Database.

## Features
- User registration and login
- Join or create groups
- Send messages within groups
- Add and download resources group-wise

## Setup
1. Create an Oracle XE database.
2. Run 'sql/create_tables.sql' to create tables.
3. Create '.env' file and fill in your database credentials.
4. Run the project

## Technologies
- Java 17+
- Swing for UI
- Oracle Database XE
- JDBC
